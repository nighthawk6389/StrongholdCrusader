# StrongholdCrusader (working repo name)

An original browser-based 3D castle-siege RTS with a modern military setting.
It is inspired by the classic castle-builder RTS genre and adds faster pacing,
a day/night stealth system and first-person control of units. It will be
deployed on Vercel.

- **Plan and open questions:** [docs/PLAN.md](docs/PLAN.md)

> The final game will ship under its own original name and assets. This repo
> name is a placeholder.
